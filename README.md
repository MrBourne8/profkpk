# Система подсчёта результатов «Профессионалы»

Единое веб-приложение для внутриколледжного этапа конкурса профессионального мастерства. Поддерживает несколько специальностей в одном конкурсе, модули, критерии, экспертов (3–6), ввод баллов секретарём и печать протоколов.

## Требования

- OSPanel (или PHP 8+ + MySQL/MariaDB)
- Расширения PHP: `pdo_mysql`

## Установка

1. Откройте в браузере `http://profkpk/` (или ваш домен OSPanel).
2. Если БД ещё не создана — перейдите на `http://profkpk/install.php`.
3. Укажите параметры MySQL (по умолчанию OSPanel: `root` без пароля, БД `profkpk`).
4. Задайте логин/пароль администратора (по умолчанию `admin` / `admin123`).
5. Войдите в систему.

## Правила оценивания

1. Из системы печатается **личный бумажный протокол** для каждого эксперта.
2. Эксперты оценивают конкурсантов в своих бланках.
3. На общем сведении каждый эксперт называет свой балл по каждому критерию.
4. **Главный эксперт** вносит в электронную систему **одну согласованную оценку**
   (например: двое поставили 0, один — 1 → в систему идёт 0).
5. У каждого критерия задаются допустимые баллы: всегда **0** и до **5** других значений;
   при вводе доступен только выбор из этого списка.
6. Итог конкурсанта = сумма согласованных баллов по всем модулям.
7. При равных итогах места совпадают.

## Роли

- **Администратор** — конкурсы, компетенции, главные эксперты, полная настройка.
- **Главный эксперт** — видит только свои компетенции; при открытии вводит свой пароль.

Назначение: админ создаёт главного эксперта → в параметрах компетенции выбирает его.
При открытии компетенции (если ГЭ назначен) показывается окно пароля.

## Навигация

1. **Конкурсы** — список конкурсов.
2. **Конкурс** — список компетенций.
3. **Компетенция** — пароль главного эксперта → рейтинг.
4. **Настройки** — конкурсанты, эксперты, критерии (параметры — админ).
5. Слева — меню по ролям.

## Типовой сценарий

1. Создать конкурс → добавить компетенцию.
2. В настройках: конкурсанты, эксперты, модули и критерии.
3. Распечатать бланки экспертов.
4. После сведения внести оценки → смотреть рейтинг → печать итогов.

## Резервное копирование

Скрипт `tools/backup_db.bat` создаёт дамп MySQL в папку `backups/`. Настройте пути к `mysqldump` под вашу установку OSPanel.
